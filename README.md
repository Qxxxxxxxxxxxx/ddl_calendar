# DDL日历

一个只使用HTML、CSS和JavaScript的轻量PWA。支持iPhone、安卓和电脑浏览器，任务默认仅存储在当前设备的IndexedDB中。

## 功能

- 完整月历，上下区域分别为月历和选中日期的DDL任务
- DDL支持无截止时间、仅日期、日期＋具体分钟；无DDL任务只出现在“全部任务→未完成→无DDL”
- 任务可以添加、编辑、完成、取消完成和删除；按DDL排序，逾期和剩余时间自动更新
- “全部任务”按未完成、已逾期、已完成切换；未完成进一步划分有DDL/无DDL
- 周期任务支持每天、每周（可选星期几）、每月和自定义每N天/周/月，支持每次分别完成、编辑单次或未来所有、删除单次或终止未来重复
- 已完成记录可一键清空，不会破坏周期任务未来的生成规则
- 完整本机备份（JSON）的导入/导出，导入支持合并或替换
- 外观深浅色切换、日历每周第一天设定、主屏幕安装和离线资源缓存

## 部署到手机（推荐）

PWA必须通过HTTPS网站（或者开发用的localhost）访问，才能正常注册Service Worker并安装离线资源。**不能保证直接在iPhone“文件”App中点开index.html时，自动保存和离线安装能正常工作。**

1. 解压整个文件夹。保留index.html、app.js、styles.css、manifest.webmanifest、sw.js以及icons目录的相对位置。
2. 将这些文件放到任意支持HTTPS的静态网站托管服务的同一站点目录，例如Netlify、Cloudflare Pages或GitHub Pages。不需要服务器程序或数据库，也不需要向网站上传个人任务数据。
3. 在iPhone Safari打开部署后的HTTPS网址，在分享菜单中选择“添加到主屏幕”，选择作为网页应用打开（可用时），从主屏幕打开。
4. 首次联网打开一次，应用资源缓存成功后可在断网环境下使用。重新部署新版本后，联网重新打开，以便更新缓存。
5. 安卓可以通过Chrome等支持PWA的浏览器打开网站，并按浏览器提示安装或添加到主屏幕（具体选项因设备浏览器而异）。

备份非常重要：iPhone和安卓分别保存自己的本机数据，不会自动同步。清除网页数据、卸载主屏幕网页应用或更换设备前，应先在“设置”中导出JSON，再到目标设备导入。

## 本地电脑预览

在此文件夹运行：

```bash
python -m http.server 8000
```

然后在浏览器打开`http://localhost:8000/`。注意：不同端口、域名和打开方式会形成不同的浏览器存储区域。

## 数据和重复任务说明

- 到期计算使用设备当前本地时区；有时间的DDL在所设的分钟开始时即视作逾期，日期限定的DDL在当天结束之后才视作逾期。
- 日历从不显示无DDL任务，已完成的任务仍保留在原DDL日期下。
- “未完成→有DDL”会列出全部单次未来DDL和未来90天的重复任务实例；可以继续点“再看90天”。重复规则仍永久有效，无论是否出现在这一列表内，都可在月历中查看相应日期。
- 已逾期和已完成的周期任务历史按起始日期生成。不要创建跨越极长年份的每日重复规则，以免首次渲染过慢。
- 修改单次重复任务会将本次转换为独立任务；修改“本次及以后”会在当前这次分割旧规则，保留此前的实例，并从新日期建立后续规则。已经提前完成的未来实例会另存为历史记录，以免意外重新变为未完成。
- 已完成批量清理会删除单次任务的完成记录，并屏蔽已完成的周期任务单次实例，不影响以后重复。
- 导入“合并”遇到相同内部ID时将生成新ID；如果导入相同的备份多次，可能产生重复任务。
- 本应用不提供锁屏通知、不发送个人数据至服务器，也不提供跨设备自动同步。

## 文件清单

- `index.html`：页面骨架和表单
- `styles.css`：响应式布局、浅色和深色主题
- `app.js`：任务操作、重复日期、IndexedDB、导入导出
- `manifest.webmanifest`：安装信息
- `sw.js`：离线缓存配置
- `icons/`：安装图标

源码可自行修改。每次修改`app.js`或`styles.css`并重新部署时，建议将`sw.js`内的`CACHE_NAME`改为新版本号，避免旧版本缓存继续被使用。
